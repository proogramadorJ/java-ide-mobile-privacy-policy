Política de privacidade

Última atualização: 13 de novembro de 2026

Esta política explica como o Java IDE Mobile, app da ByteCraft para escrever, compilar e executar programas Java no Android, trata os seus dados.

Resumo: o app não tem cadastro, anúncios nem analytics. Seus projetos ficam no aparelho e só saem dele quando você usa uma função de rede, direto para o serviço que você escolheu. A ByteCraft recebe só relatórios de falha, quando o app fecha por um erro, e você pode desligá-los.

Dados que o app usa

Ficam só no aparelho, no armazenamento privado do app:

  • seus projetos, arquivos e o histórico do git;
  • as configurações (tema, tamanho da fonte, argumentos de compilação e execução);
  • o nome e o e-mail que você informar como identidade do git, gravados nos seus commits;
  • os tokens de acesso que você cadastrar para remotos git e, se você entrar com a conta do GitHub, o seu nome de usuário e o token de acesso, criptografados;
  • as dependências Maven baixadas e os arquivos internos do compilador e do autocompletar, que rodam no próprio aparelho.

O app não coleta localização, contatos, identificadores de publicidade nem estatísticas de uso.

Quando dados saem do aparelho

A ByteCraft não vende nem compartilha dados. Algo sai do aparelho só nestes casos:

  • Relatórios de falha (Firebase Crashlytics, do Google): se o app fecha por um erro, ele envia o erro e o rastro da pilha, a versão do app, o modelo do aparelho, a versão do Android, o estado do aparelho no momento (memória, espaço livre, orientação), um identificador aleatório da instalação e, como em qualquer acesso à internet, o endereço IP. Não vão seus projetos, seu código, seus arquivos nem seus tokens. O Google processa esses dados em nome da ByteCraft, só para corrigirmos erros. Para desligar: Configurações → Privacidade. Política: https://firebase.google.com/support/privacy
  • Maven Central (Sonatype): ao buscar uma dependência, o termo buscado vai para search.maven.org; ao compilar um projeto Maven, bibliotecas e plugins são baixados de repo1.maven.org. Como em qualquer acesso à internet, o serviço recebe o endereço IP do aparelho. Política: https://www.sonatype.com/privacy-policy
  • Servidores git que você escolher (por exemplo, GitHub ou GitLab): clone, pull e push trocam o conteúdo do repositório com o endereço remoto informado. O token cadastrado para um servidor é enviado só para ele, para autenticar. O que acontece lá segue a política desse serviço.
  • Conta do GitHub (opcional): se você tocar em "Entrar com o GitHub", a autorização acontece na página do próprio GitHub, no navegador; o app não vê sua senha. O GitHub entrega ao app um token de acesso aos seus repositórios, que o app usa só para falar com api.github.com e github.com: ler seu nome de usuário, listar seus repositórios, criar um repositório quando você publica um projeto, e clonar, fazer pull e push. Política do GitHub: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement
  • Programas que você executa: o seu código e os comandos do terminal (como curl ou git) podem acessar a internet. O app não vê nem guarda esse tráfego.

Ao exportar um projeto em .zip, o arquivo vai só para o local que você escolher no seletor do Android.

Backup do Android

Se o backup do Android estiver ligado na sua conta Google, o sistema pode copiar os projetos e as configurações do app para esse backup, conforme a política do Google. Os tokens dos remotos git, o ambiente Java e as dependências baixadas ficam fora do backup.

Permissões

  • Internet e estado da rede: para as funções de rede descritas acima.
  • Notificações e serviço em primeiro plano: mantêm o terminal e os programas em execução quando o app vai para o segundo plano, com uma notificação que permite encerrar tudo.

O app não pede acesso aos seus arquivos, câmera, microfone, localização ou contatos. Importar e exportar projetos usa o seletor de arquivos do Android, só com o que você escolher.

Por quanto tempo os dados ficam

Tudo o que está no aparelho fica até você apagar (o projeto, o token, a conta do GitHub ou a identidade do git, nas telas do app) ou desinstalar o app. Limpar os dados do app nas configurações do Android também apaga tudo. Os relatórios de falha ficam no Firebase por 90 dias e depois são apagados. O que foi enviado ao Maven Central, ao GitHub ou a outro servidor git segue os prazos desses serviços. Para revogar o acesso do app à sua conta do GitHub, use github.com/settings/applications.

Segurança

Os dados do app ficam no armazenamento privado dele, que outros apps não acessam. Os tokens são criptografados (AES) com uma chave da Android Keystore, que não sai do aparelho, e só existem em texto aberto na memória durante o comando git. Os relatórios de falha, a busca e os downloads do Maven usam HTTPS; para os remotos git, use endereços https://.

Crianças

O app é destinado a pessoas a partir de 13 anos e não é voltado a crianças. Ele não coleta dados de ninguém, inclusive de crianças.

Seus direitos (LGPD)

Pela Lei Geral de Proteção de Dados (Lei 13.709/2018), você pode pedir confirmação do tratamento, acesso, correção, exclusão e portabilidade dos seus dados, além de informações sobre compartilhamento. Fora os relatórios de falha, a ByteCraft não recebe dados seus: você mesmo vê, altera e apaga tudo no app. Os relatórios não incluem nome nem e-mail, são apagados após 90 dias e podem ser desligados a qualquer momento; a base legal é o legítimo interesse de manter o app funcionando. Os demais dados só vão a terceiros para executar o que você pediu (busca, download, login no GitHub ou operação git). Dúvidas ou pedidos: bytecraftappsdev@gmail.com. Respondemos em até 15 dias.

Mudanças nesta política

Se o app passar a tratar dados de outra forma, esta política será atualizada antes da versão que trouxer a mudança, com a nova data no topo, no app e no site.
