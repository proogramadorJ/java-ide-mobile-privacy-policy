Privacy policy

Last updated: November 13, 2026

This policy explains how Java IDE Mobile, an app by ByteCraft for writing, compiling and running Java programs on Android, handles your data.

In short: the app has no sign-up, ads or analytics. Your projects stay on the device and only leave it when you use a network feature, going straight to the service you chose. ByteCraft only receives crash reports when the app closes because of an error, and you can turn them off.

Data the app uses

Kept only on the device, in the app's private storage:

  • your projects, files and git history;
  • settings (theme, font size, compile and run arguments);
  • the name and email you enter as your git identity, which are written into your commits;
  • access tokens you add for git remotes and, if you sign in with GitHub, your GitHub username and access token, encrypted;
  • downloaded Maven dependencies and the internal files of the compiler and code completion, which run on the device itself.

The app does not collect location, contacts, advertising IDs or usage statistics.

When data leaves the device

ByteCraft does not sell or share data. Something leaves the device only in these cases:

  • Crash reports (Firebase Crashlytics, by Google): if the app closes because of an error, it sends the error and stack trace, the app version, the device model, the Android version, the device state at that moment (memory, free space, orientation), a random installation identifier and, as with any internet access, the IP address. Your projects, code, files and tokens are not sent. Google processes this data on behalf of ByteCraft, only so we can fix errors. To turn it off: Settings → Privacy. Policy: https://firebase.google.com/support/privacy
  • Maven Central (Sonatype): when you search for a dependency, the search term goes to search.maven.org; when a Maven project builds, libraries and plugins are downloaded from repo1.maven.org. As with any internet access, the service receives the device's IP address. Policy: https://www.sonatype.com/privacy-policy
  • Git servers you choose (for example GitHub or GitLab): clone, pull and push exchange the repository contents with the remote address you entered. The token you added for a server is sent only to that server, to authenticate. What happens there follows that service's policy.
  • GitHub account (optional): if you tap "Sign in with GitHub", authorization happens on GitHub's own page, in the browser; the app never sees your password. GitHub gives the app an access token to your repositories, which the app uses only to talk to api.github.com and github.com: read your username, list your repositories, create a repository when you publish a project, and clone, pull and push. GitHub's policy: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement
  • Programs you run: your own code and terminal commands (such as curl or git) can access the internet. The app does not see or store that traffic.

When you export a project as a .zip, the file only goes to the location you pick in the Android file picker.

Android backup

If Android backup is turned on for your Google account, the system may copy the app's projects and settings to that backup, under Google's policy. Git remote tokens, the Java environment and downloaded dependencies are excluded from backup.

Permissions

  • Internet and network state: for the network features described above.
  • Notifications and foreground service: keep the terminal and running programs alive when the app goes to the background, with a notification that lets you stop everything.

The app does not ask for access to your files, camera, microphone, location or contacts. Importing and exporting projects uses the Android file picker, only with what you choose.

How long data is kept

Everything on the device stays until you delete it (the project, token, GitHub account or git identity, in the app's screens) or uninstall the app. Clearing the app's data in Android settings also deletes everything. Crash reports are kept in Firebase for 90 days and then deleted. Whatever was sent to Maven Central, GitHub or another git server follows those services' retention periods. To revoke the app's access to your GitHub account, use github.com/settings/applications.

Security

The app's data stays in its private storage, which other apps cannot access. Tokens are encrypted (AES) with an Android Keystore key that never leaves the device, and only exist in plain text in memory while a git command runs. Crash reports, Maven search and downloads use HTTPS; for git remotes, use https:// addresses.

Children

The app is intended for people aged 13 and over and is not directed at children. It does not collect data from anyone, children included.

Your rights

Under data protection laws such as Brazil's LGPD and the GDPR, you may ask for confirmation of processing, access, correction, deletion and portability of your data, and for information about sharing. Apart from crash reports, ByteCraft receives none of your data: you can see, change and delete everything yourself in the app. Crash reports contain no name or email, are deleted after 90 days and can be turned off at any time; the legal basis is our legitimate interest in keeping the app working. Other data only goes to third parties to carry out what you asked for (a search, a download, a GitHub sign-in or a git operation). Questions or requests: bytecraftappsdev@gmail.com. We reply within 15 days.

Changes to this policy

If the app starts handling data differently, this policy will be updated before the version that brings the change, with the new date at the top, in the app and on the website.
